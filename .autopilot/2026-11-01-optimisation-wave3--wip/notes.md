## 7. Риски и ограничения (факты)

- Один классический скрипт, глобальная область: top-level `const/let/function` в base/core/roles/data/help и `globalThis.X = ...` в IIFE-экранах — единственная «шина» между файлами; screens — 100+ файлов-IIFE. Файлы кросс-зависимы по порядку NNN: например 150-monitor.js (routes) оборачивает `liveTick`; 760 (orders) оборачивает `DRAWERS.create` и `ACT.saveLoad`; 410 (dashboard) пишет `HOOKS.status`; 085 (hubs) читает `S.jobs` из data.js; 400-rec-core.js (shared) оборачивает `globalThis.audit`; 001 (shell) вызывает `shellSearchBox`/`ops`/`ssccFromScan` из orders; core.js проверяет наличие через `typeof fn === 'function'` (shellSearchBox, shellTopExtra, shellTopMore, shellEyebrow, shellOverlays, gsInput, a11ySideLink, a11yOverlay, recordsNavHtml, shellSideExtra, printHead, wnLink, hubFilter, hubOfLoad). Много областей пушит вкладки в ЧУЖОЙ экран: `addTab('orders', ...)` из 760/505/420; `addTab('dashboard',...)` из 410; `addTab('settings', ...)` из 440/450/460/615/620; `addTab('billing', ...)` из 430/600/720; `addTab('routes', ...)` из 150/340/350/360; `addTab('dispatch', ...)` из 160/240/260/265/710; `addTab('reports', ...)` из 610/611/730; `addTab('fleet'...)` из 300/305/310; `addTab('drivers', ...)` из 320/330/761. Папка screens/<area>/ НЕ равна «чанку, достаточному для экрана»; зависимости идут через shared/ (005-kzmap, 400-rec-core, 700-list-views) и shell/.
- Рендер вызывает `SCREENS[S.route]`, `tabsOf(id)`; `Object.keys(SCREENS)`, `NAV`, `ROLES`, `HELP.articles`, `S.alarms/inbox/bookings` используются глобальным поиском, баннером, тестами и справкой на любом экране -> ленивая загрузка/инициализация областей должна оставлять эти реестры заполненными либо учитывать, что тесты (например 62-language-audit.js: `walk(Object.keys(SCREENS))`, 10-navigation: обход всех NAV) сразу после загрузки страницы ожидают все экраны.
- Тесты вызывают `go`, `ACT.*`, `S.*` СРАЗУ после `fresh()` и затем синхронно читают DOM; чанки, догружаемые асинхронно, сломают это без «eager»-режима (single-file) для тестов.
- В коде НЕТ `eval`/`new Function` (только в тестах `w.eval`), НЕТ `'use strict'`; inline-обработчик ровно один: `onclick="event.stopPropagation()"` в 440-rec-refdata.js:170. Все события делегированы на `document` (69 `document.addEventListener(...)`), т.е. частичный render не требует перепривязки, но обработчики `input`/`change` завязаны на `id` и `data-*`.
- Тик (FR-194) трогает `l.temp`, `l.progress` в `S.loads` и историю `TH.hist`; рендер дашборда/маршрутов/хабов читает эти значения из шаблонов, пометок `data-live` на значениях нет. `perfProbe` и тест `S.liveAt === null` в iframe завязаны на имена `liveTick`, `S.liveAt`, `S.simOn`.
- Фокус/прокрутка: a11y-обёртка (002-a11y.js:128) возвращает фокус по подписи после ПОЛНОГО render; при частичном рендере часть этой логики нужна/станет лишней; `scrollKeep` определяет «тот же контекст» через route|tab|drawer.
- Каждый render: полный `shell()` + `nameControls` + `a11yPass` (getComputedStyle по всем div/section/aside/ul/table/pre) + `syncUrl` + `helpDecorate`; `lvWrap` парсит таблицы через `template.innerHTML` на каждом показе вкладок со списками.
- Состояние хранится в `S` и в замыканиях IIFE (`C`, `RC`, `TH`, `Q`, `IB`, `PT`, `R5`, `RES`...); глобальных `getter`ов мало. `S.toast` — один слот; `toast()` вызывает render() дважды.
- `demoReset` снимает слепок только по SNAP_KEYS; остальное восстанавливается перезагрузкой страницы; `snapshot()` делается на DOMContentLoaded после всех файлов.
- Хранилище: iframe-тесты работают в одном origin с харнесом; настройки в localStorage защищены `window.frameElement` (kz-a11y, olymp.lang, olymp.design), но `kz-r4-views` (700-list-views.js:15-18) и `kokzhol.v6.whatsnew.seen` (990-delivery.js:54) не проверяют фрейм.
- Языковое переключение: ссылки `.langs a` — навигация на другой файл страницы (полная перезагрузка), состояние перенесено через sessionStorage `olymp.state`; при per-language сборке эта механика не меняется (каждая страница и так отдельная), но ссылки на `de.html`/`en.html`/`kk.html` должны остаться (`fileFor`, core.js:4).
- `index.html` (ru) может редиректить на другой язык из localStorage (langStart) — не в iframe.
- `build-v6.mjs --lang ru` собирает подмножество (но `finishDelivery`/manifest/sw строятся только по выбранным страницам, тест f0-delivery.js:19-30 ждёт все пять страниц).
- Билд-артефакты `platform/*.html`, `sw.js`, `assets/manifest.json` — закоммичены (CI делает `git commit` `[skip ci]`); `roles.js` содержит `VERSION = '6.5.2'` (стр. 3): память проекта требует поднимать VERSION перед каждым push; `sw.js` имя кэша зависит от VERSION и хеша содержимого.
