# Pflichtenheft — реализованные функции (техническое задание исполнителя)

**Olymp Logistic Platform** · Состояние на 16.10.2026 · версия платформы 0.3.9

## 1 Назначение

Pflichtenheft описывает, **как** требования Lastenheft реализованы в платформе — для каждого требования LH-… решение PH-…, место в интерфейсе и статус. Основа — код версии 0.3.9 и реестр изменений (FR-01…190, BUG-01…37).

## 2 Обзор системы

- Бэкенд FastAPI + PostgreSQL 16, миграции БД (Alembic), операционное состояние по сущностям с версиями и дельта-ответами.
- Веб-приложение React (Vite), онлайн-демо в браузере с вымышленными данными и тем же поведением, что и сервер (тест паритета).
- Безопасность: Argon2id, 2FA TOTP, блокировка, CSRF, CSP/HSTS, разделение по хабам, матрица RBAC, шифрование персональных данных, журнал аудита с цепочкой HMAC.
- Эксплуатация: стек Docker Compose, усиленные контейнеры, сервис интеграций — единственный с доступом в интернет, зашифрованные резервные копии, проверки состояния.
- Качество: ≈ 1 560 тестов бэкенда (в том числе в случайном порядке), 757 UI-тестов в браузере и против реального бэкенда, 121 тест вёрстки, доступность axe, CI параллельными частями.
- Языки: RU, DE, EN, KK; реестр изменений на трёх языках; номер версии со временем сборки.

**Архитектура:** браузер → nginx (TLS, заголовки безопасности, ограничение частоты) → API (FastAPI, только внутренняя сеть) → PostgreSQL (раздельные роли владельца и среды выполнения, триггер аудита). Сервис интеграций — единственный с доступом в интернет (список разрешённых адресов). Онлайн-демо полностью работает в браузере с вымышленными данными.

**Хранение данных:** реляционные таблицы рейсов, заказов, позиций, мест, бронирований, клиентов, водителей, тревог, затрат; операционное состояние по сущностям (JSONB) с версиями; версионируемые справочники; персональные поля зашифрованы (контекст таблица/столбец/строка).
