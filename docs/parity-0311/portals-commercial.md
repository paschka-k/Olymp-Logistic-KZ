# Parity 0.3.11 → v6.4.3 · Customer & partner portals, public pages, commercial

Field/behaviour-level comparison (2026-10-29). Reference: `origin/main` of Olymp-Logistic-Platform (0.3.11, React + FastAPI). Target: `platform-src/v6` of Olymp-Logistic-KZ (v6.4.3). Screen-level gaps already listed in `docs/PARITY-0.3.10-v6.md` are not repeated. The three items ported on 2026-10-29 (street/address block, load row temp-class/pallets/weight/avg, manual check) are skipped.

Legend: ✅ same · ◐ present but different / cut down · ❌ missing. Severity: **A** wrong or blocking behaviour / missing function · **B** missing sub-function, validation or hint · **C** layout / UX detail.
